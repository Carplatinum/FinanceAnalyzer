# Финансовый Ассистент 
Проект для автоматизации учёта личных финансов с аналитикой расходов, кешбэком и инструментами для инвестиций.  

## Установка

1. Клонируйте репозиторий:

git clone https://github.com/Carplatinum/FA

## 🚀 Запуск проекта

1. Установите зависимости:
pip install pandas requests openpyxl pytest flask
2. Настройте API-ключи:
В utils.py замените YOUR_API_KEY на реальный ключ Finnhub
api_url = "https://finnhub.io/api/v1/...&token=YOUR_API_KEY"  
3. Запустите основной модуль:
python -m src.main
